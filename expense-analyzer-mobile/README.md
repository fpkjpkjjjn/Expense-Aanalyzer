# Expense Analyzer — мобильное приложение (React Native / Expo)

Тёмный минималистичный интерфейс из двух экранов:
1. **Мои траты** — вводишь траты вручную (дата, описание, сумма) прямо в приложении
2. **Отчёт** — общая сумма, диаграммы по категориям и неделям, топ-5 трат

Никакой загрузки файлов — категория определяется автоматически по описанию
(например «Пятёрочка» → Groceries), это делает backend.

## Шаг 1. Настрой адрес сервера

Открой `src/config.js` и замени IP на реальный IP своего компьютера в локальной
сети (см. README бэкенда, как его узнать):

```js
export const API_BASE_URL = "http://147.232.182.182:5000";
```

**Важно:** `localhost` тут не сработает — с точки зрения телефона localhost
это он сам, а не твой компьютер.

## Шаг 2. Установи зависимости

Нужен установленный Node.js (18+). Дальше:

```bash
npm install
```

## Шаг 3. Запусти сервер разработки Expo

```bash
npm start
```

Если телефон в одной сети с компьютером, но Metro показывает адрес
`127.0.0.1` вместо реального IP — запусти так:

```bash
set REACT_NATIVE_PACKAGER_HOSTNAME=твой_IP
npx expo start -c
```

## Шаг 4. Открой на телефоне

1. Установи приложение **Expo Go** из App Store / Google Play
2. Отсканируй QR-код камерой телефона (iOS) или прямо в приложении Expo Go (Android)
3. Телефон и компьютер должны быть в одной Wi-Fi сети

**Важно:** путь к папке проекта должен состоять только из латинских букв
(без кириллицы) — иначе Metro-сервер падает с ошибкой заголовков.

## Как пользоваться

1. На главном экране заполни дату, описание и сумму траты → «Добавить трату»
2. Повтори для всех трат, которые хочешь проанализировать
3. Нажми «Проанализировать» — откроется отчёт с диаграммами
4. «Добавить ещё траты» на отчёте вернёт к вводу для нового анализа

## Структура проекта

```
App.js                          — точка входа, навигация, тёмная тема
src/config.js                   — адрес backend-сервера (единственное, что нужно править)
src/theme.js                    — цвета, отступы, типографика тёмной темы
src/api/client.js               — запросы к Flask API
src/screens/EntryScreen.js      — ввод трат вручную + список введённого
src/screens/ReportScreen.js     — экран с результатами анализа
src/components/CategoryPieChart.js — круговая диаграмма по категориям
src/components/WeeklyBarChart.js   — столбчатая диаграмма по неделям
```

## Что дальше (если захочется развивать)

- **Публикация в сторы**: понадобится `expo build` / EAS Build, аккаунт
  разработчика Apple ($99/год) и Google Play ($25 разово)
- **Работа без Wi-Fi к серверу**: задеплоить backend на бесплатный хостинг
  (Render, Railway) и указать его адрес в `config.js`
- **История трат**: сейчас приложение ничего не сохраняет между запусками —
  можно добавить локальное хранилище (AsyncStorage), чтобы список трат не
  пропадал при перезапуске
